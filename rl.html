Learning by acting, and by imagining

An agent acts, gets rewards, and improves. Compute values with dynamic programming over a 3D state space, learn them from experience with Q-learning, compare exploration strategies, run policy gradients, and see why learning a model of the world lets an agent practise in its head.

Concept 01

MDPs, returns and dynamic programming

Reinforcement learning is framed as a Markov decision process: states s, actions a, transition probabilities P(s'|s,a), rewards r and a discount γ. The agent wants to maximise the return, the discounted sum of future rewards:

G_t = r_t + γ·r_(t+1) + γ²·r_(t+2) + … V^π(s) = E[ G_t | s_t = s, policy π ] Q^π(s,a) = E[ G_t | s_t = s, a_t = a, then π ] Bellman optimality: V*(s) = max_a Σ_s' P(s'|s,a) · [ r(s,a,s') + γ·V*(s') ]

When the model P and r are known, dynamic programming solves it directly. Value iteration repeats the Bellman backup on every state until the values stop changing. The policy is then to take the action with the best backed-up value. Discount γ near 0 makes the agent short-sighted, and near 1 far-sighted.

Python · value iteration
import numpy as np

def value_iteration(P, R, gamma=0.95, tol=1e-6):
    # P: (A, S, S) transition probabilities, R: (S, A) expected rewards
    A, S, _ = P.shape
    V = np.zeros(S)
    while True:
        Q = R + gamma * np.einsum("ast,t->sa", P, V)     # Bellman backup for every (s, a)
        V_new = Q.max(axis=1)
        if np.abs(V_new - V).max() < tol:
            return V_new, Q.argmax(axis=1)               # values and greedy policy
        V = V_new

Learner tips

  • Dynamic programming needs the model and a small state space. Everything after this page relaxes one of those two requirements.
  • The Bellman equation says a state's value equals the immediate reward plus the discounted value of where you land. Nearly every RL algorithm is a way of satisfying it.
Concept 02

Q-learning: learning values from experience

If the model is unknown, the agent learns by trying things. Q-learning keeps a table of action values and nudges each one toward a bootstrapped target after every step:

δ = r + γ · max_a' Q(s', a') − Q(s, a) (temporal-difference error) Q(s, a) ← Q(s, a) + α · δ

It is off-policy: it learns about the greedy policy while behaving with an exploratory one such as ε-greedy (random action with probability ε). α is the learning rate. Deep Q-networks (DQN) replace the table with a neural network and add a replay buffer and a target network for stability.

Python · tabular Q-learning
import numpy as np

def q_learning(env, episodes=500, alpha=0.5, gamma=0.95, eps=0.2):
    Q = np.zeros((env.n_states, env.n_actions))
    rng = np.random.default_rng(0)
    for _ in range(episodes):
        s, done = env.reset(), False
        while not done:
            a = rng.integers(env.n_actions) if rng.random() < eps else Q[s].argmax()
            s2, r, done = env.step(a)
            target = r + gamma * Q[s2].max() * (not done)     # no bootstrap after a terminal state
            Q[s, a] += alpha * (target - Q[s, a])
            s = s2
    return Q

Common traps

  • With ε = 0 the agent can lock onto the first path it finds and never discover a better one. With a very high ε it keeps wandering. Decay ε over time.
  • Rewards that are far away or rare (sparse) make learning slow. Reward shaping helps but can create loopholes the agent will exploit.
  • Function approximation plus bootstrapping plus off-policy data can diverge. That is the reason for target networks and replay.
Concept 03

Exploration versus exploitation: bandits

The simplest RL problem has no states: pull one of several slot machines, each with an unknown payout rate. You must balance exploiting the best-looking arm and exploring others. Strategies are compared by regret, the reward lost compared with always pulling the best arm.

ε-greedy: explore with probability ε, otherwise the arm with the highest average UCB1: choose argmax_a [ mean_a + c · √( ln t / n_a ) ] (optimism under uncertainty) Thompson: sample a payout rate for each arm from its Beta posterior, pull the best sample

Concept 04

Policy gradients, actor-critic and PPO

Instead of learning values and acting greedily, policy gradient methods learn the policy π_θ(a|s) directly and push its probabilities up for actions that led to high return:

∇J(θ) = E[ ∇ log π_θ(a|s) · A(s,a) ] A = G − b (advantage: return minus a baseline) actor-critic: a critic V_φ(s) provides the baseline, A ≈ r + γV(s') − V(s) PPO: L = E[ min( ρ·A, clip(ρ, 1−ε, 1+ε)·A ) ], ρ = π_new(a|s) / π_old(a|s)

The baseline does not change the expected gradient but cuts its variance a lot. PPO's clipping stops any single update from moving the policy too far, which makes training stable. It is the workhorse behind many robotics results and the RL step in much LLM post-training.

Python · the PPO loss
import torch

def ppo_loss(logp_new, logp_old, adv, values, returns, entropy, clip=0.2, vf=0.5, ent=0.01):
    ratio = torch.exp(logp_new - logp_old)
    adv = (adv - adv.mean()) / (adv.std() + 1e-8)                    # normalise advantages
    surr = torch.min(ratio * adv, torch.clamp(ratio, 1 - clip, 1 + clip) * adv)
    policy_loss = -surr.mean()
    value_loss = (values - returns).pow(2).mean()
    return policy_loss + vf * value_loss - ent * entropy.mean()      # entropy bonus keeps exploring

Concept 05

World models: learning to imagine

Model-free methods need huge numbers of real interactions. A world model learns the environment's dynamics, how the next state and reward follow from the current state and an action, so the agent can plan or practise inside the model instead of the world.

encode: z_t = enc(o_t) compress observations into a latent state dynamics: z_(t+1) ~ f(z_t, a_t) predict what happens next reward: r_t ≈ g(z_t, a_t) plan: choose actions whose imagined rollouts in f give the best return

Landmarks, in rough order: Dyna (Sutton, 1990) mixed real experience with simulated updates from a learned model. World Models (Ha and Schmidhuber, 2018) trained a VAE for vision, an RNN for dynamics and a tiny controller. MuZero (DeepMind, 2019) learned a latent model that predicts only what is useful for planning (value, policy, reward) and searched in it. The Dreamer family (Hafner et al., 2019 to 2023) learns a latent dynamics model and trains the policy entirely on imagined rollouts. JEPA (LeCun, 2022 proposal; I-JEPA and V-JEPA models since) learns to predict in representation space rather than pixels. Large video world models such as Genie (DeepMind, 2024) generate interactive environments from learned dynamics.

The payoff is sample efficiency, shown below. The risk is model error: planners exploit mistakes in an imperfect model, so errors compound over long imagined rollouts.

Python · a latent dynamics model and random-shooting planner
import torch, torch.nn as nn

class WorldModel(nn.Module):
    def __init__(self, obs=8, act=2, z=32):
        super().__init__()
        self.enc = nn.Sequential(nn.Linear(obs, 64), nn.ReLU(), nn.Linear(64, z))
        self.dyn = nn.Sequential(nn.Linear(z + act, 64), nn.ReLU(), nn.Linear(64, z))
        self.rew = nn.Sequential(nn.Linear(z + act, 64), nn.ReLU(), nn.Linear(64, 1))

    def loss(self, o, a, o_next, r):
        z, z_next = self.enc(o), self.enc(o_next).detach()
        za = torch.cat([z, a], -1)
        return ((self.dyn(za) - z_next) ** 2).mean() + ((self.rew(za).squeeze(-1) - r) ** 2).mean()

@torch.no_grad()
def plan(model, o, horizon=12, candidates=256, act_dim=2):
    z = model.enc(o).expand(candidates, -1)
    A = torch.rand(candidates, horizon, act_dim) * 2 - 1              # random action sequences
    ret = torch.zeros(candidates)
    for t in range(horizon):                                           # imagine forward in latent space
        za = torch.cat([z, A[:, t]], -1)
        ret += model.rew(za).squeeze(-1)
        z = model.dyn(za)
    return A[ret.argmax(), 0]                                          # execute only the first action

Learner tips

  • Re-plan every step (model predictive control) and execute only the first action, so model errors do not pile up.
  • Predicting in latent space avoids modelling every pixel, which wastes capacity on irrelevant detail.
  • Use an ensemble of models and treat disagreement as uncertainty, to avoid trusting a region the model has never seen.
Concept 06

Small but important concepts

The vocabulary and tricks every RL project leans on.

Discount factor γ

Weights future rewards. Also keeps infinite-horizon returns finite.

G = Σ γᵏ r_(t+k)
gamma = 0.99

Return versus reward

Reward is one step's feedback. Return is the discounted total the agent actually optimises.

G_t = r_t + γ·G_(t+1)
G = r + gamma * G

Temporal-difference error

The gap between the bootstrapped target and the current estimate. Drives all TD learning.

δ = r + γV(s') − V(s)
delta = r + gamma * V[s2] - V[s]

On-policy versus off-policy

On-policy learns from data made by the current policy. Off-policy can reuse older data, for example from a replay buffer.

PPO is on-policy, SAC and DQN are off-policy
buffer.sample(256)

Replay buffer

Store transitions and train on random minibatches. Breaks correlation between consecutive steps and reuses data.

batch ~ Uniform(buffer)
random.sample(buffer, 256)

Target network

A slowly updated copy of the network used to compute targets, so the target does not chase itself.

θ⁻ ← τθ + (1−τ)θ⁻
soft_update(target, online, tau=0.005)

Advantage

How much better an action is than the policy's average in that state.

A(s,a) = Q(s,a) − V(s)
adv = returns - values

GAE

Generalised advantage estimation blends n-step returns to trade bias against variance.

A = Σ (γλ)ᵏ δ_(t+k)
compute_gae(rewards, values, gamma, lam)

Entropy bonus

Reward policy randomness to keep exploring and avoid early collapse.

J + β·H(π)
loss -= 0.01 * dist.entropy().mean()

Reward shaping

Add extra rewards that guide learning. Potential-based shaping provably keeps the optimal policy.

r' = r + γΦ(s') − Φ(s)
reward += gamma * phi(s2) - phi(s)

Sparse rewards

Feedback only at the end. Hard to learn from. Use curriculum, shaping, demonstrations or intrinsic curiosity.

r = 0 almost everywhere
curriculum = [easy, medium, hard]

Offline RL

Learn a policy from a fixed dataset without interacting. Needs care to avoid trusting actions never seen.

maximise Q while staying near the data
CQL, IQL, behaviour cloning baseline

Imitation learning

Learn directly from expert demonstrations as supervised learning. A strong start before RL.

min ‖π(s) − a_expert‖²
F.mse_loss(policy(s), a_expert)

Sim-to-real

Train in simulation, then deploy on hardware. Randomise physics so the policy survives the gap.

domain randomisation
mass = rng.uniform(0.8, 1.2)

RLHF as RL

Language-model tuning treats the model as a policy, a reward model as the environment and PPO-style updates, with a KL penalty to the starting model.

max E[r(x,y)] − β·KL(π ‖ π_ref)
kl_penalty = beta * (logp - logp_ref)

# Gradient

An interactive guide to machine learning, from linear regression to world models and production systems. Each concept has a short explanation, the formula, code and a demo that runs in your browser, with 3D demos for the transformer, diffusion, fine-tuning and reinforcement learning.
I have built this website with all my learnings and experiences from corporate gained during working on various projects.

## Pages

- Classical ML (with model explanation), Neural nets, Vision & sequences, Transformers & LLMs
- Training & fine-tuning: pretraining and scaling laws, SFT, LoRA and QLoRA, DPO and RLHF, GRPO, quantisation
- Applied LLMs: production RAG, tool calling and agents, structured output, reasoning, evals, CLIP, guardrails
- Generative models, RL & world models
- Production & scaling: FSDP and ZeRO, pipeline parallelism, vLLM batching and KV cache, experiment tracking, drift, A/B tests, rollout
- Playbook: debugging guide, learning-rate range test, glossary and quiz

Please note that, the demos use small toy data to show how ideas behave. They are not production-scale results.

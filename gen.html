Concept 01

Autoencoders, PCA and the VAE

An autoencoder squeezes data through a narrow bottleneck and tries to rebuild it. To succeed it must keep the important structure and discard the rest. The simplest case is linear: the best linear 1-D bottleneck is exactly the first principal component from PCA.

encoder: z = f(x) decoder: x̂ = g(z) loss = ‖x − x̂‖² PCA: project onto the direction of largest variance

A plain autoencoder has gaps in its latent space, so random points decode to junk. A variational autoencoder (VAE) fixes this. The encoder outputs a mean and variance, a latent is sampled from that Gaussian, and a KL term keeps the latents close to a standard normal. The latent space becomes smooth, so sampling from N(0, I) and decoding generates new data.

z = μ(x) + σ(x) ⊙ ε, ε ~ N(0, I) (reparameterisation trick) loss = ‖x − x̂‖² + β · KL( N(μ, σ²) ‖ N(0, I) ) KL = −½ Σ ( 1 + log σ² − μ² − σ² )

Python · a small VAE in PyTorch
import torch, torch.nn as nn, torch.nn.functional as F

class VAE(nn.Module):
    def __init__(self, d_in=784, d_z=16):
        super().__init__()
        self.enc = nn.Sequential(nn.Linear(d_in, 256), nn.ReLU())
        self.mu, self.logvar = nn.Linear(256, d_z), nn.Linear(256, d_z)
        self.dec = nn.Sequential(nn.Linear(d_z, 256), nn.ReLU(), nn.Linear(256, d_in))
    def forward(self, x):
        h = self.enc(x)
        mu, logvar = self.mu(h), self.logvar(h)
        z = mu + torch.randn_like(mu) * torch.exp(0.5 * logvar)       # reparameterisation
        return self.dec(z), mu, logvar

def vae_loss(x, x_hat, mu, logvar, beta=1.0):
    recon = F.mse_loss(x_hat, x, reduction="sum") / x.size(0)
    kl = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp()) / x.size(0)
    return recon + beta * kl

Learner tips

  • The weight β trades sharpness for smoothness. Large β gives a tidy latent space but blurrier outputs.
  • VAE images look blurry because the pixel loss averages over possibilities. That is why latent diffusion models use a VAE only as a compressor and let diffusion do the generating.
Concept 02

Generative adversarial networks

A GAN trains two networks in a game. The generator G turns noise into samples. The discriminator D tries to tell real from fake. G is rewarded for fooling D.

min_G max_D E_x~data[ log D(x) ] + E_z~noise[ log(1 − D(G(z))) ] for a fixed G the best discriminator is D*(x) = p_data(x) / ( p_data(x) + p_G(x) )

When the generator matches the data perfectly, D* equals ½ everywhere: the discriminator cannot do better than guessing. GANs give sharp samples and fast generation but are notoriously hard to train: they can mode collapse (cover only a few kinds of samples) or oscillate.

Python · one GAN training step
import torch, torch.nn as nn

G = nn.Sequential(nn.Linear(64, 256), nn.ReLU(), nn.Linear(256, 784), nn.Tanh())
D = nn.Sequential(nn.Linear(784, 256), nn.LeakyReLU(0.2), nn.Linear(256, 1))
optG = torch.optim.Adam(G.parameters(), 2e-4, betas=(0.5, 0.999))
optD = torch.optim.Adam(D.parameters(), 2e-4, betas=(0.5, 0.999))
bce = nn.BCEWithLogitsLoss()

def step(real):                                  # real: (B, 784)
    B = real.size(0)
    fake = G(torch.randn(B, 64))
    # 1) discriminator: real -> 1, fake -> 0
    lossD = bce(D(real), torch.ones(B, 1)) + bce(D(fake.detach()), torch.zeros(B, 1))
    optD.zero_grad(); lossD.backward(); optD.step()
    # 2) generator: make D say 1 for fakes (the non-saturating loss)
    lossG = bce(D(fake), torch.ones(B, 1))
    optG.zero_grad(); lossG.backward(); optG.step()

Industry now

  • GANs are fast at inference and still appear in super-resolution, real-time video and some audio. For image and video generation, products are built on diffusion and flow-matching models, which train more stably and cover the data better.
Concept 03

Diffusion models in 3D

Diffusion models turn generation into many small denoising steps. The forward process gradually mixes data with Gaussian noise until nothing is left but noise. A network is trained to undo one step, and sampling starts from pure noise and applies the learned reverse step repeatedly.

forward (closed form): x_t = √ᾱ_t · x₀ + √(1 − ᾱ_t) · ε, ε ~ N(0, I) training loss: E ‖ ε − ε_θ(x_t, t) ‖² (predict the noise) DDIM step (η = 0): x̂₀ = (x_t − √(1−ᾱ_t)·ε_θ) / √ᾱ_t x_(t−1) = √ᾱ_(t−1) · x̂₀ + √(1 − ᾱ_(t−1)) · ε_θ

ᾱt falls from about 1 (clean) to about 0 (pure noise) along the noise schedule. Predicting the noise is equivalent to learning the score, the direction toward higher data density: ∇ log p(x_t) = −ε_θ / √(1−ᾱ_t).

Python · DDPM training step and DDIM sampling loop
import torch, math

T = 1000
ab = torch.tensor([math.cos((t / T + 0.008) / 1.008 * math.pi / 2) ** 2 for t in range(T + 1)])
ab = ab / ab[0]                                            # cosine schedule: alpha-bar

def train_step(model, x0, opt):
    t = torch.randint(1, T + 1, (x0.size(0),))
    eps = torch.randn_like(x0)
    a = ab[t].view(-1, *[1] * (x0.dim() - 1))
    xt = a.sqrt() * x0 + (1 - a).sqrt() * eps               # noise the data
    loss = ((model(xt, t) - eps) ** 2).mean()                # predict the noise
    opt.zero_grad(); loss.backward(); opt.step()
    return loss.item()

@torch.no_grad()
def sample(model, shape, steps=50):
    x = torch.randn(shape)
    ts = torch.linspace(T, 0, steps + 1).long()
    for t, t_prev in zip(ts[:-1], ts[1:]):
        eps = model(x, t.expand(shape[0]))
        x0 = (x - (1 - ab[t]).sqrt() * eps) / ab[t].sqrt()
        x = ab[t_prev].sqrt() * x0 + (1 - ab[t_prev]).sqrt() * eps    # DDIM, eta = 0
    return x

Learner tips

  • Fewer sampling steps (DDIM, DPM-Solver, distillation) trade a little quality for large speed gains.
  • An exact score on a finite dataset reproduces the training points. Real networks generalise because they are smooth and share structure across inputs.
  • The noise schedule matters. Very noisy start points need enough steps near the high-noise end, where structure is decided.
Concept 04

Guidance, latents and modern designs

Text-to-image systems add three ideas on top of plain diffusion:

  • Latent diffusion. Run diffusion in the compressed latent space of a VAE rather than pixels. It is far cheaper, and a decoder turns the final latent back into an image.
  • Conditioning. A text encoder produces embeddings that the denoiser (a U-Net or a diffusion transformer, DiT) reads through cross-attention.
  • Classifier-free guidance (CFG). Train with the condition randomly dropped, then at sampling time push the prediction away from the unconditional one and toward the conditional one.
ε̃ = ε_uncond + w · ( ε_cond − ε_uncond ) w = 1 is plain conditional sampling; w > 1 follows the prompt harder equivalent target density: p̃(x) ∝ p(x | c)^w · p(x)^(1−w)

Flow matching (and rectified flow) is a close relative: it trains a network to predict the velocity along a straight path from noise to data, which allows sampling in few steps. Several recent image and video models use it.

Concept 05

Small but important concepts

Terms you will see in every generative paper.

KL divergence

How far one distribution is from another. Not symmetric, and zero only when they match.

KL(p‖q) = Σ p · log(p / q)
F.kl_div(q.log(), p, reduction="batchmean")

ELBO

The VAE objective: a lower bound on data log-likelihood. Reconstruction minus a KL regulariser.

log p(x) ≥ E_q[log p(x|z)] − KL(q(z|x)‖p(z))
loss = recon + beta * kl

Noise schedule

Controls how fast signal is destroyed. Linear, cosine and shifted schedules all exist.

ᾱ_t = Π (1 − β_s)
ab = torch.cumprod(1 - betas, 0)

Signal-to-noise ratio

How much clean signal versus noise a latent holds at step t. Many modern parametrisations are built around it.

SNR(t) = ᾱ_t / (1 − ᾱ_t)
snr = ab / (1 - ab)

Score function

The gradient of the log density. Points toward more likely data. Diffusion learns it for noisy data.

s(x) = ∇ₓ log p(x)
torch.autograd.grad(log_p.sum(), x)

v-prediction

Predict a mix of noise and data instead of noise alone. More stable at extreme noise levels.

v = √ᾱ·ε − √(1−ᾱ)·x₀
target = a.sqrt() * eps - (1 - a).sqrt() * x0

Classifier guidance

Steer sampling with the gradient of a separate classifier. CFG replaced it by using the model itself.

∇ₓ log p(c | x_t) added to the score
grad = autograd.grad(logp_c, x_t)

U-Net and DiT

Two common denoiser designs. A U-Net is a convolutional encoder–decoder with skip links. A DiT is a transformer over patches.

ε_θ(x_t, t, c)
DiT(depth=28, hidden=1152, patch=2)

FID

Fréchet Inception Distance: compares statistics of real and generated image features. Lower is better.

FID = ‖μ₁ − μ₂‖² + Tr(Σ₁ + Σ₂ − 2(Σ₁Σ₂)^½)

Mode collapse

A GAN generator that produces only a few outputs because they fool D.

p_G covers a small part of p_data
minibatch discrimination, Wasserstein loss

Uses an earth-mover distance for a smoother, more informative gradient than the original loss.

Inpainting

Fill a masked region by running diffusion while keeping the known pixels fixed at each step.

x_t = m ⊙ x_t^known + (1−m) ⊙ x_t^gen

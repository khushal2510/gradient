03 · Vision and sequences

Convolutions, recurrence and state spaces

Different data needs different structure. Images have local patterns, so we slide small filters over them. Sequences have order, so we carry a memory forward. State space models do this memory-keeping with clean linear maths and have become a serious alternative to attention.

Concept 01

Convolution: sliding a small filter

A convolutional layer slides a small grid of weights, the kernel, across the image. At each position it multiplies the overlapping pixels by the kernel and adds them up. Because the same kernel is reused everywhere, the layer has few parameters and detects a pattern wherever it appears (translation equivariance).

out[i, j] = Σₐ Σ_b kernel[a, b] · image[i + a, j + b] (+ bias)

Early layers learn edges and blobs. Later layers combine them into textures, parts and objects. Pooling shrinks the map by keeping the maximum (or average) of each small window, which adds tolerance to small shifts.

Python · a small CNN in PyTorch
import torch, torch.nn as nn

class SmallCNN(nn.Module):
    def __init__(self, n_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 8, kernel_size=5), nn.ReLU(), nn.MaxPool2d(2),     # 28 -> 24 -> 12
            nn.Conv2d(8, 16, kernel_size=5), nn.ReLU(), nn.MaxPool2d(2),    # 12 -> 8 -> 4
        )
        self.head = nn.Linear(16 * 4 * 4, n_classes)

    def forward(self, x):
        x = self.features(x)
        return self.head(x.flatten(1))

print(SmallCNN()(torch.randn(2, 1, 28, 28)).shape)      # torch.Size([2, 10])

Learner tips

  • Real kernels are learned, not designed. The Sobel and blur kernels above are just hand-made examples of what a learned filter can become.
  • Use padding (for example padding=1 with a 3×3 kernel) to keep the spatial size and avoid shrinking too fast.
  • For small datasets, start from a pretrained backbone (ResNet, EfficientNet, ConvNeXt) and fine-tune.
Concept 02

Shapes, strides and parameter counts

Most CNN bugs are shape bugs. The output size of a convolution along one dimension is

out = floor( (W + 2P − K) / S ) + 1 params = K · K · C_in · C_out + C_out MACs ≈ out² · K² · C_in · C_out

where W is input size, K kernel size, S stride and P padding. Doubling channels roughly quadruples the cost of the layer.

Concept 03

Recurrent networks and the vanishing gradient

A recurrent network reads a sequence one step at a time and carries a hidden state h that summarises what it has seen:

hₜ = tanh( W·hₜ₋₁ + U·xₜ + b ) yₜ = V·hₜ

To train it we unroll it through time and backpropagate (BPTT). The gradient reaching a step far in the past is a product of many factors, one per step. If each factor is a little below one, the product vanishes. If it is a little above one, it explodes.

LSTM and GRU add gates so the cell state can pass information forward almost unchanged:

fₜ = σ(W_f·[hₜ₋₁, xₜ] + b_f) forget gate iₜ = σ(W_i·[hₜ₋₁, xₜ] + b_i) input gate c̃ₜ = tanh(W_c·[hₜ₋₁, xₜ] + b_c) candidate cₜ = fₜ ⊙ cₜ₋₁ + iₜ ⊙ c̃ₜ cell state oₜ = σ(W_o·[hₜ₋₁, xₜ] + b_o) output gate hₜ = oₜ ⊙ tanh(cₜ)

Python · an LSTM with gradient clipping
import torch, torch.nn as nn

class SeqModel(nn.Module):
    def __init__(self, vocab, d=128):
        super().__init__()
        self.emb = nn.Embedding(vocab, d)
        self.rnn = nn.LSTM(d, d, batch_first=True)
        self.out = nn.Linear(d, vocab)
    def forward(self, tokens):
        h, _ = self.rnn(self.emb(tokens))
        return self.out(h)                       # logits for the next token at every step

model = SeqModel(vocab=1000)
opt = torch.optim.Adam(model.parameters(), 1e-3)
x = torch.randint(0, 1000, (8, 30))
loss = nn.functional.cross_entropy(model(x[:, :-1]).transpose(1, 2), x[:, 1:])
loss.backward()
torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)   # tames exploding gradients
opt.step()

Learner tips

  • Gradient clipping fixes exploding gradients. Gates (LSTM, GRU) fix vanishing ones.
  • Initialise the LSTM forget-gate bias to about 1 so it starts by remembering.
  • RNNs process steps one after another, so they train slowly on modern hardware. This is the main reason transformers displaced them.

Industry now

  • LSTMs and GRUs are still used for small, low-latency or streaming models, but most sequence work in industry uses transformers. State space models such as Mamba are a growing alternative for very long sequences.
  • The vanishing-gradient idea still matters: residual connections and normalisation solve the same problem in transformers.
Concept 04

State space models: Mamba and friends

A state space model (SSM) comes from control theory. A hidden state vector h evolves under a linear rule driven by the input, and the output reads from the state:

continuous: h'(t) = A·h(t) + B·x(t) y(t) = C·h(t) + D·x(t) discretised: hₜ = Ā·hₜ₋₁ + B̄·xₜ yₜ = C·hₜ Ā = exp(Δ·A) B̄ = (Δ·A)⁻¹ (exp(Δ·A) − I) · Δ·B (zero-order hold)

Because the system is linear, the same model has two equivalent forms. As a recurrence it needs constant memory per step, which makes inference cheap. As a convolution with kernel K = (CB̄, CĀB̄, CĀ²B̄, …) it can be trained in parallel over the whole sequence. Cost grows linearly with length, where attention grows quadratically.

S4 showed that a carefully structured A (HiPPO initialisation) lets an SSM remember very long ranges. Mamba then made the parameters Δ, B, C depend on the current input (a selective SSM). That lets the model choose what to store or forget, which fixed linear SSMs cannot do. The recurrence is then no longer a plain convolution, so Mamba uses a hardware-aware parallel scan instead.

The key number is the eigenvalues of Ā. Eigenvalues close to 1 in magnitude mean long memory; smaller ones forget quickly; complex ones make the state rotate, which captures oscillations.

Python · a diagonal SSM as recurrence and as convolution
import numpy as np

n, T = 4, 64
rng = np.random.default_rng(0)
A = np.exp(-rng.uniform(0.02, 0.3, n)) * np.exp(1j * rng.uniform(0, 1, n))   # complex diagonal Abar
B = rng.normal(size=n) + 0j
C = rng.normal(size=n) + 0j
x = rng.normal(size=T)

# 1) recurrence: constant memory per step (good for inference)
h = np.zeros(n, dtype=complex); y_rec = []
for t in range(T):
    h = A * h + B * x[t]
    y_rec.append((C * h).sum().real)

# 2) convolution: K[k] = C A^k B, then y = K * x (good for parallel training)
K = np.array([(C * A**k * B).sum().real for k in range(T)])
y_conv = np.array([np.dot(K[:t + 1][::-1], x[:t + 1]) for t in range(T)])
print(np.allclose(y_rec, y_conv))      # True
Python · the idea behind Mamba's selective scan (sequential reference)
import torch

def selective_scan(x, delta, A, B, C):
    # x: (T, d)   delta: (T, d)   A: (d, n)   B, C: (T, n)  -- B, C, delta depend on the input
    T, d = x.shape
    h = torch.zeros(d, A.shape[1])
    ys = []
    for t in range(T):
        dA = torch.exp(delta[t].unsqueeze(-1) * A)                  # (d, n) discretised A
        dB = delta[t].unsqueeze(-1) * B[t].unsqueeze(0)             # (d, n) discretised B
        h = dA * h + dB * x[t].unsqueeze(-1)                        # selective state update
        ys.append((h * C[t].unsqueeze(0)).sum(-1))                  # read out
    return torch.stack(ys)          # real implementations replace this loop with a parallel scan

Common traps

  • Pure SSMs can struggle with exact recall (copy this exact string from far back), where attention is strong. That is why many recent models are hybrids with a few attention layers.
  • Stability needs the eigenvalues of Ā inside the unit circle. Parameterising A as a negative real part before discretising keeps it stable.
Concept 05

Small but important concepts

Details that keep coming up in vision and sequence work.

Receptive field

The region of the input that influences one unit. Stacking 3×3 layers grows it by 2 each layer.

RF_l = RF_{l−1} + (K−1)·jump
torchinfo.summary(model, (1,3,224,224))

1×1 convolution

Mixes channels at each pixel without looking at neighbours. Cheap way to change channel count.

out = W · channels at (i, j)
nn.Conv2d(256, 64, kernel_size=1)

Depthwise separable convolution

A per-channel spatial filter followed by a 1×1 mix. Far fewer parameters, used in MobileNet.

params ≈ K²·C + C·C_out
nn.Conv2d(C, C, 3, groups=C)

Global average pooling

Average each channel over all positions instead of flattening. Removes a big dense layer.

y_c = mean over (i, j) of feature_c
nn.AdaptiveAvgPool2d(1)

Dilated convolution

Spaces the kernel taps apart to see a wider area with the same parameter count.

effective K = K + (K−1)(d−1)
nn.Conv2d(C, C, 3, dilation=2)

Intersection over union

Overlap measure between two boxes. Used to score detections and to suppress duplicates.

IoU = area(A ∩ B) / area(A ∪ B)
torchvision.ops.box_iou(a, b)

Non-maximum suppression

Keep the highest-scoring box and drop others that overlap it too much.

drop box if IoU > threshold
torchvision.ops.nms(boxes, scores, 0.5)

Teacher forcing

During training feed the true previous token, not the model's own guess. Fast, but creates a train/test mismatch.

input_t = y_true_{t−1}
logits = model(tokens[:, :-1])

Padding and masking

Batch sequences by padding to equal length, then mask the padding so it affects neither attention nor loss.

loss only where mask = 1
CrossEntropyLoss(ignore_index=PAD)

Perplexity

How surprised a language model is by held-out text. Lower is better.

PPL = exp(cross-entropy)
math.exp(loss.item())

Bidirectional RNN

Run one RNN forward and one backward, then concatenate. Sees both past and future context.

h = [h_fwd ; h_bwd]
nn.LSTM(d, d, bidirectional=True)

Stride versus pooling

A stride-2 convolution downsamples while learning its filter, so modern designs often use it instead of pooling.

out = floor((W + 2P − K)/S) + 1
nn.Conv2d(C, C, 3, stride=2, padding=1)

Zero-order hold

The assumption that the input stays constant between samples, used to discretise a continuous SSM.

Ā = exp(ΔA)
scipy.signal.cont2discrete((A, B, C, D), dt)

HiPPO

A way to initialise A so the state compresses the whole input history onto orthogonal polynomials. The base of S4.

h tracks polynomial coefficients of history
(see the S4 repository)
